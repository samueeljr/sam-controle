## Detalhes da Documentação

### 1. Relatório Acadêmico (`manual-pim-II.pdf`)
* Contém a introdução, fundamentação teórica, arquitetura do sistema e considerações finais exigidas pelo projeto.

### 2. Gestão e Requisitos (`/Scrum`)

* **Histórias de Utilizador (User Stories):** Descrições centradas no utilizador para entrega incremental de valor.

### 3. Modelagem de Sistema (`/Diagramas`)
* Arquitetura visual mapeando os fluxos de interação e a estrutura de dados implementada nos módulos em C.
