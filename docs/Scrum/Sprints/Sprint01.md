**Status:** Concluída.

## Sprint Goal

Estruturar a base do programa em C e entregar o menu principal de navegação do sistema.

## Product Backlog Items

- Estrutura base do sistema (sem user story própria)

## Tasks

- [x] Organizar a estrutura de arquivos e módulos do projeto em C
- [x] Implementar o menu principal do sistema
- [x] Definir os arquivos de texto (`.txt`) usados para guardar os dados

## Definition of Done

Todos os itens devem atender à [DoD](../Definition-of-Done.md).

## Sprint Review

- **Incremento entregue:** Estrutura base do programa em C e menu principal de navegação.
- **Demonstração:** Execução do programa no terminal, navegando pelas opções do menu.
- **Resultado:** o objetivo da sprint foi atingido e os itens planejados foram concluídos.

## Retrospective

### Funcionou bem

O objetivo da sprint foi atingido e todas as tasks foram concluídas. O menu principal ficou organizado e serviu de base para as funcionalidades das sprints seguintes.

### Problemas

Nenhum.

### Melhorias

Como melhoria futura, o grupo pretende migrar o armazenamento dos arquivos de texto (`.txt`), criados nesta sprint, para um banco de dados, de preferência o SQL Server, o que traria mais segurança, integridade e desempenho para os dados de todo o sistema.
